# @zhixing/owner-services

Owner-side domain services for Zhixing, including advancement control, review scheduling, recovery maintenance, and deferred schedule-intent handling.

This package supplies implementation services to the Zhixing host. It is not a standalone service product or an independently supported SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
