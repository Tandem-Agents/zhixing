# @zhixing/owner-kernel

Conversation-owner kernel for Zhixing. It coordinates conversation authority, durable run admission and commit, confirmation aggregation, assignments, and related ownership boundaries.

This is an internal consistency component consumed by Zhixing's host and server layers. It is not a standalone persistence product or an independently supported SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
