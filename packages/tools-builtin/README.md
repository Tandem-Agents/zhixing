# @zhixing/tools-builtin

Zhixing's built-in file, search, shell, web-content, scheduling, and Skill tools, implemented against the runtime's permission and effect boundaries.

This is a tool implementation package consumed by Zhixing's runtime. It is not a standalone command suite or an independently supported tool SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
