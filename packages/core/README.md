# @zhixing/core

Core runtime and domain contracts for Zhixing, including the agent loop, event model, tool pipeline, security primitives, and durable domain boundaries.

This is a foundational implementation package consumed by other Zhixing packages. Its exported subpaths support the coordinated Zhixing release and are not a separate general-purpose SDK stability promise.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
