# @zhixing/orchestrator

Kernel runtime assembly and orchestration for Zhixing, including run-envelope handling, sub-agent lifecycle, task execution, and confirmation integration.

This is an internal runtime component consumed by Zhixing hosts. Its exported subpaths are part of the coordinated Zhixing package set, not a separate orchestration SDK promise.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
