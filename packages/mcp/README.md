# @zhixing/mcp

MCP host integration for Zhixing. It connects configured Model Context Protocol servers and exposes their tools through Zhixing's controlled tool boundary.

This package is consumed by the Zhixing runtime; it is not a standalone MCP client application or an independently supported SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
