# @zhixing/executor

Executor-role runtime for Zhixing. It supplies assignment execution, durable assignment coordination, and the ports used by an Executor host.

This is an internal runtime component consumed by the Zhixing host and CLI. It is not a standalone worker product or an independently supported SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
