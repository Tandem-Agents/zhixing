# @zhixing/mesh

Authenticated device-mesh infrastructure for Zhixing, including pairing, secure sessions, outbound tunnels, relay primitives, and recovery-checkpoint transport.

This is a topology and transport component consumed by Zhixing hosts. It is not a standalone mesh service or an independently supported networking SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
