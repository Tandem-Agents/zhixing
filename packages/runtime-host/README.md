# @zhixing/runtime-host

Generic AgentRuntime assembly for Zhixing, with frozen runtime projections and adapters between Kernel runs and conversation ownership.

This is an internal host component used by Zhixing's production runtime shapes. It is not a standalone application host or an independently supported SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
