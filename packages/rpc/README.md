# @zhixing/rpc

RPC bindings and runtime-event projections for Zhixing, including session streams, broadcasts, confirmations, and finite Product API client bindings.

This is a protocol-binding component consumed by Zhixing's server and CLI surfaces. It is not a standalone remote API product or an independently supported SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
