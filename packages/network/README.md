# @zhixing/network

Network-egress primitives for Zhixing, including SSRF-resistant fetch behavior, URL and IP validation, and response-text sanitization.

This is a supporting security package used by Zhixing's runtime integrations. It is not a standalone proxy product or an independently supported networking SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
