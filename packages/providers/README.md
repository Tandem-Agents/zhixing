# @zhixing/providers

LLM provider integration for Zhixing, including provider adapters, preset registration, public configuration parsing, and workspace resolution.

This is a supporting runtime package consumed by Zhixing. It is not a standalone model gateway or a guarantee of an independent provider SDK surface.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
