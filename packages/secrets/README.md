# @zhixing/secrets

Device-local secret storage for Zhixing, including platform key protection and the encrypted vault used for provider, channel, and MCP bindings.

This is a security-sensitive implementation package consumed by Zhixing. It is not a standalone credential manager or an independently supported secret-storage SDK.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
