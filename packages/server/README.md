# @zhixing/server

Persistent HTTP, WebSocket, and JSON-RPC gateway for Zhixing. It binds authenticated transport requests to the finite product and runtime contracts supplied by the host.

This is an internal gateway component consumed by Zhixing's CLI-hosted service. It is not a standalone server product or an independently supported public API.

End users should install `@zhixing/cli` and follow the [Zhixing user guide](https://github.com/Tandem-Agents/zhixing#readme). Report package issues through [GitHub Issues](https://github.com/Tandem-Agents/zhixing/issues).
