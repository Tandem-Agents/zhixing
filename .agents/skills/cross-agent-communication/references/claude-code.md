# Claude Code 接收说明

本机适配器通过 VS Code Claude Code 宿主提供的通信上下文向已登记会话投递。接收身份与路径取自 `collab/mailbox/tool/config.json`，不按标题或最近活动猜收件人。

## 调用

使用[会话信箱](local-adapters.md#会话信箱)，目标别名为 `claude`，实际映射以本机配置为准。

## 既有验证（2026-11-09）

- 已验证：Windows 本机实例的目标会话自动接收与关联回复；消息完整性、去重、顺序、目标会话校验、恢复、Windows 管道、忙闲、配置保持及 Hook 身份绑定。
- 已验证：适配器退出后由宿主生命周期 Hook 恢复，继续使用原会话。
- 未验证：Claude Code 客户端完整退出后重开。宿主升级、通信上下文缺失或权限拒绝时重新核查；验证结论仅适用于已验实例。

## 生命周期与维护

项目本地 `SessionStart`、`UserPromptSubmit`、`Stop`、`StopFailure` Hook 启动目标会话所属适配器，无需模型续挂。只使用宿主给该子进程的通信上下文；缺失时停在 `activation-required`，不读凭据或其他进程环境。原会话关闭时退出，恢复时补扫待办。

首次加载需要目标会话触发正常生命周期事件，使用 `status` 核对实际生效状态。`uninstall` 只移除本工具的 Hook 并停用适配器，保留信件与结果。未知投递结果不盲目重发；自动投递故障时可通过信箱手动收取，须明确标为手动方式，不能据此认定自动接收正常。
