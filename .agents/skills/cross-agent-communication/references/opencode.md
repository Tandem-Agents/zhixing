# OpenCode 接收说明

| 项目 | 登记 |
| --- | --- |
| 接收身份 | 信件绑定的 `ses_...` 会话 ID |
| 接收方式 | 已安装插件使用现有 server 的 `client.session.promptAsync` |
| 本机部署 | `collab/bridge/`；角色别名到会话 ID 的映射保存在本机配置 |
| 结果含义 | API 接受或 processed 不代表模型已经处理，更不代表任务完成 |

## 调用与边界

按[本机文件桥](local-adapters.md#本机文件桥)的命令调用，接收别名替换为配置中实际绑定 OpenCode 会话的别名。首次选择实例或登记变化时核对 README 与 status；岗位别名不能替代会话 ID，避免按旧映射误投。

插件在已有 server 内使用自身 client，不向调用方提供认证信息；按信件绑定的 session 投递，不按最近活跃会话猜测。

缺目标/模型、权限拒绝或插件不在线须如实记录。忙时排队、重启和故障恢复以该实例既有证据为准；插件磁盘更新与宿主实际加载分开核对。消息身份、文件格式、回执及失败处理沿用共享实例说明和[消息处理与维护](usage-and-verification.md)。
