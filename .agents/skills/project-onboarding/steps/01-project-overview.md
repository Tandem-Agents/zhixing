# 项目整体了解

## Objective

先整体了解当前项目，建立项目定位、结构、模块、入口和常用命令的初始印象。

## Resources

None

## Instructions

1. 阅读项目根目录中的项目说明、配置文件和维护说明，优先关注 `README`、`AGENTS.md`、包管理配置、脚本配置和工作区配置。
2. 查看根目录结构和主要子目录，识别源码、包、测试、研究文档、脚本、构建产物和配置所在位置。
3. 识别主要模块、入口文件、CLI / server / package 边界，以及常用开发、构建、测试命令。
4. 只建立整体印象，不深入专题文档，也不提前整理最终项目报告。
5. 完成当前 step 后，准备当前 output 和 handoff，再使用本文件底部的 `Next` 进入下一步。

## Output

产出一份项目整体印象笔记，包含：

- 项目定位；
- 目录结构概览；
- 主要模块和入口；
- 常用命令；
- 当前仍不确定、需要后续确认的信息。

## Completion Criteria

- 已经能用几句话说明项目是做什么的。
- 已经知道主要代码、文档、测试和配置大致在哪里。
- 已经整理出下一步阅读核心文档时需要带上的上下文。

## Handoff

向下一步传递：

- 项目定位和整体结构；
- 主要模块、入口和常用命令；
- 已发现但尚未确认的问题；
- 需要在核心文档阅读中重点验证的上下文。

准备好以上 handoff 后，再读取 `Next` 指向的文件。
