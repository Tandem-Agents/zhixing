# 决策记录

将会被后续执行、复核或交接依赖的决定记入现有任务产物，引用已有讨论，不重复抄写。决策分级与咨询要求见[决策规则](../../../../docs/workbench/cross-session-collaboration.md#311-决策门与协作模式)。

```markdown
- 决策：<要解决的选择>
  - 依据：<需求、事实、备选方案及取舍理由>
  - 对方判断：<消息或产物引用>
  - 结论：<选定方案及负责人>
  - 异议：<原始意见引用；无则省略>
  - 待办：<尚需验证、追审或用户裁决的事项；无则省略>
```

低代价、可逆的执行选择若影响后续理解，一句话说明依据即可；不逐次记录读文件、命名等操作。应先咨询但无法取得回复时，记录阻碍和允许推进的边界，不能把沉默当作认可。结论被新证据推翻时保留原决定并标明更正及依据。
