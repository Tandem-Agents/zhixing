# 持续协作的角色登记

需要跨回合跟进或移交时，在 `collab/roles/<role-slug>.md` 保存角色身份和未完成事项。

```markdown
# <角色名>
- 角色 slug：<稳定角色ID>
- 当前会话：<客户端、会话名称与稳定ID>
- 职责边界：<协调、实施或审查的具体范围>
- 状态：idle|working|waiting|inactive|unmapped
- open_threads：
  - <thread-id>：<当前阶段、等待谁、下一步行动>
```

角色本人维护；更换会话时更新映射，保留未完成事项。职责或等待状态变化时更新记录；恢复时只核对自己负责的事项。任务指定实施方不意味着已持有写权，修改共享产物仍须取得写租约。
