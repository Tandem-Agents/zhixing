# 共同分析

适用于根因分析、方案设计等需要独立判断的开放问题。

1. 协调者提供原始需求、事实、约束和完成条件，按[输入规则](../../../../docs/workbench/cross-session-collaboration.md#312-任务书保真中继失真防护)标明材料来源。默认两方；增加参与者须说明他要消除的具体不确定性，重大任务的冷读另按终审要求安排。
2. 各方先独立形成方案、依据、风险和反对自身方案的最强理由，记录后再读对方结论；允许自行补充证据。交叉前的初稿保留，后续修正注明依据。
3. 交换质询，指出会影响结果的优点、缺口或反例，再各自重新判断。分歧没有新证据时，转向查证或验证。
4. 协调者汇总共同结论及残余分歧，实施方完成目标要求的成果。各方的具体改进或独立核验证据随结论保留；不为证明贡献制造差异。
5. 各方分别亲自对照原始需求验收成果，先记录依据再交换判断。有缺口就继续处理，达标后结束；统一判据见[状态与推进](../../../../docs/workbench/cross-session-collaboration.md#35-状态与推进)。

争议证据充分且取舍在授权内时，由已指定的决策负责人选择方案并记录理由、异议和可推翻该选择的新证据。存在未解决的阻断缺陷或有依据的未达标异议时，不得单方宣布完成；用户保留的决定交由用户裁决。协调与分歧处理细则见[共同分析规则](../../../../docs/workbench/cross-session-collaboration.md#51-多角度分析2-3-角色星型)。
