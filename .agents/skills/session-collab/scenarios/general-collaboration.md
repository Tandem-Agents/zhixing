# 咨询与交接

适用于既定方案的具体疑问、任务分工和结果交接。单纯传递事实或一次性问答直接使用消息，不要求新建线程、角色登记或决策日志。

1. 说明本次问题、必要事实和需要对方交回什么。涉及方案取舍时附选项、推荐、依据及最不确定之处；对方应给出自己的判断及理由。
2. 需要对方结果才能继续时，注明阻塞点和时限；接收方无法及时完成，应说明已知判断、未查明之处和后续安排。按[等待与回复规则](../../../../docs/workbench/cross-session-collaboration.md#37-回复义务与超时)处理，不把确认收到当作结果。
3. 将影响后续执行或验收的决定保存在现有任务产物中，可用[决策日志](../templates/decision-log.md)；只涉及传输的确认留在消息记录中。
4. 交付成果仍按[达标核验](../../../../docs/workbench/cross-session-collaboration.md#35-状态与推进)由双方检查；未完成项说明由谁继续、还缺什么。

用户要求独立判断、需探索未知方案或审查已有成果时，分别使用[共同分析](multi-perspective.md)或[独立复核](review.md)。已有候选方案不免除独立复核。
