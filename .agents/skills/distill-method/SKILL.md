# 经验与方法提炼

从具体个案中沉淀长期复用的方法或规则时，必须同时满足以下三条标准：

1. **真实正向有效**：纸面通顺不等于方法有效。必须在不预知答案的条件下，拿原始输入或同类新场景做真实盲测，确认照此执行能直接逼近目标结果；每次修改后重测受影响部分，效果下滑立即纠偏或回退。
2. **基于本质通用抽象**：穿透具体试错与表层症状，找出背后的共同根因与结构性规律；提炼出的方法必须跨同类场景通用，不得耦合原题细节、暗藏特定答案或针对单一漏洞打局部补丁。
3. **面向使用者表达**：明确谁在什么时机使用该材料，按 [write-for-readers](../write-for-readers/SKILL.md) 组织定位与语言——直给可执行的判断与做法，不混入试错流水账、内部黑话，也不把期望达成的目标口号当成方法本身，并归入职责匹配的唯一载体。
