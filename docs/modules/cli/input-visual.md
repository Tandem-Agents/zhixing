# 输入区视觉

本文承接[CLI 视觉设计语言](visual-language.md)，覆盖 REPL 与配置编辑器的 `input` / `add-model` 输入面板；候选面板、历史回显与底部信息行属于 REPL。补全触发、候选数据、材料采集和命令执行不在本文定义。

## 核心边界

正在编辑的内容必须一眼可识别；提交后的内容是历史，不再占用编辑容器。长输入通过换行呈现，不靠横向滚动隐藏内容；输入光标由输入布局决定，不随外部状态或模型输出跳动。

这不是把 shell 提示符加粗，而是为日常对话提供稳定的输入空间。只给当前编辑区域保留框体重量，避免长会话的历史反复堆框。

## REPL 各状态的形态

| 状态 | 视觉合同 |
|---|---|
| 空输入 | 圆角完整框，品牌色 `❯`；空态说明放在框外固定提示行，编辑行仅保留草稿和光标 |
| 编辑中 | 已提交到应用的字符进入草稿后隐藏空态说明，提示行高度不变；终端自行渲染尚未提交的 IME 组合文字 |
| 多行 | 按内容换行扩展，续行对齐提示符之后；按可见列宽而非字符数布局 |
| 候选面板 | 输入框与候选框各自完整、顺序排列，不嵌套、不共用边框；普通选中态采用同源点阵纹理，删除准备态改用红底，不叠加纹理以免损坏可读性 |
| 已提交 | 移除编辑框，以灰底用户消息进入历史；不带 `❯`，前导留白、背景补齐行宽，长文本按宽度折行，并非强制压成一行 |
| 输入取消 | 未提交内容不作为用户消息写入历史；不能将此规则扩大成取消已执行运行时删除既有历史 |
| 底部信息区 | 当前输入场景固定一行，左侧说明、右侧操作；共享公告跨场景保留，场景内容随当前交互切换，不重复叠加信息行 |

历史灰底标识“谁说的”，候选纹理标识“选中了什么”，框体标识“在哪里编辑”，三者不可互相替代。历史消息不带 `❯`，既避免与当前输入混淆，也让用户复制时不夹带提示符。

## 当前布局与职责

[UI 根](../../../packages/terminal-ui/src/root.tsx)统一组织主输入、配置字段、临时输入和候选。输入使用原生文本编辑器与自适应完整框，按真实字素和列宽计算换行、选区与光标。空态说明不进入编辑行；硬件光标对应真实编辑位置，供系统 IME 定位。

主输入、配置字段和临时输入共用框体与公共信息行；秘密字段掩码显示，不进入普通草稿存储。同页刷新保留编辑和光标，粘贴未完成时不提交，迟到结果不能覆盖已经改变的光标、选区或草稿。

候选与配置列表共用点阵选中纹理，危险项用红色表达。提交后的历史使用灰底原文，消息/工具保持静态菱形，M1 十帧、每帧 300ms；回显只定义显示，不代替实际业务接纳。

## 底部信息行

`InformationBoard` 是同一终端的信息容器；各输入交互持有独立场景和来源句柄，共用左右布局。容器只接收内容，不认识命令、授权、输入 buffer 或业务状态。

- 同步提示由当前场景直接投影：空草稿说明、普通输入的清空提示、候选快捷键、临时输入或选择面板的提示，不保存第二份提示状态。
- 动态来源取得独立发布句柄并更新具名内容；不同来源互不覆盖。共享公告跨场景保留，场景内容只属于本次交互；更新不改变其他来源。
- 主输入暂停时隐藏其局部内容，恢复时读取当前内容；交互结束释放局部来源及订阅，迟到写入无效，其他来源保留。
- 屏幕只订阅当前输入区；动态内容变更无需键盘事件即可刷新，同轮变更合并，无变化不重画。替换、卸载和退出解除订阅，独占屏期间不写入主屏内容。
- 普通输入、候选、临时文本输入、授权和通用选择使用相同布局；空内容也占位。左右独立对齐，窄窗口右区优先、左区截短，遵守可见列宽。候选沿用原末行，不另叠一行。
- 信息行两侧各留 2 列，与 CLI 内容缩进同源；同侧块间和左右内容之间至少留 2 列。渲染器先扣除外侧留白再分配预算，右侧截短后仍保持右对齐。小于 5 列时对称缩小留白，至少保留一列内容；输出不超整行预算。
- 场景只提供内容、左右归属和有效期，不自行拼外侧缩进或扣减留白宽度。候选的直接渲染、接入公共容器及辅助说明复用同一间距原语；辅助说明保留原有行位，公共公告只呈现一次。信息行紧接所属框体或面板的既有末行位置，内容变化不增加空行、不移动编辑光标。

## 实现与核查入口

终端由 [`terminal-ui/root.tsx`](../../../packages/terminal-ui/src/root.tsx) 统一组织输入与公共信息行。共同约束如下：

- 主输入、配置字段和临时文本输入共用自适应完整框；空态说明、字段说明和候选帮助进入同一左右信息行。列宽由原生文本引擎计算，来源只管理内容与有效期。
- [`InformationBoard`](../../../packages/terminal-ui/src/information-model.ts) 隔离发布来源和场景；共享公告保留，主输入暂停后可恢复，已结束页面的迟到发布失效。同页数据刷新不重置字段、光标或当前选项。
- 候选与配置列表共用选中纹理规则；危险项以红色表达。用户历史使用整行灰底，消息与工具保留静态菱形，M1 保持十帧、每帧 300ms。
- 正文按稳定源节点维护原生组件，阅读与选区使用源坐标。滚轮只由一个处理者消费；页面更新和尺寸变化按源位置恢复，不能从正在改变的布局反复重算锚点。选区保留原始文本范围，包括中英混排和跨节点选择；点击正文不抢占编辑焦点。
- 优先消费宿主提供的粘贴；若鼠标模式下宿主把右键交给应用，由 N 经受管剪贴板读取器接入同一材料/草稿通路，不关闭滚轮。空粘贴不改变输入，读取及平台回退共用 1.5 秒命令预算并确认 helper 关闭。专用字段不进入普通草稿存储，粘贴完成前不提交；字段继续编辑、移动光标或改变选区后不应用迟到结果，同页状态刷新不取消仍适用的粘贴。复制保留明确的选区动作。
