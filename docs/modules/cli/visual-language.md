# CLI 视觉设计语言

本文定义终端各页面和历史内容共享的视觉语言；输入区具体形态见[输入区视觉](input-visual.md)。它不定义输入补全、业务流程或屏幕调度架构。

## 设计取舍

知行是日常使用的个人助手，CLI 是持续工作的“家”，不是用完即走的脚本工具。界面要有工具的克制与陪伴的温度，既不冷峻，也不卡通化；不靠增加装饰获得层级，不照搬其他智能体的外观。

| 场景 | 体验目标与设计依据 |
|---|---|
| 首次配置 | 不慌：步骤和下一步明确，允许返回修改，视觉重量轻 |
| 日常对话 | 专注：不抢注意力，只在必要时提示 |
| 长会话 | 安心：上下文余量与运行状态可见，避免毫无预告地中断工作 |
| 错误／中断 | 可控：说明哪里出错、能如何继续，错误色不刺眼 |

把按钮、状态和选项都当作着色文字，会使可操作性与层级不清；应以形状、留白和语义样式表达职责，而不是继续增加颜色。

- **安静**：弱化常态信息，按需提示，不使用卡通装饰或无意义闪烁。
- **边界与层级分开**：框体界定独立空间，留白、缩进和章节标记表达层级，不堆叠嵌套框。
- **状态不能只靠颜色**：图标与文字共同表达就绪、待补和未启用；颜色只作强化。
- **中文优先，混排可读且对齐**：中文是主要阅读语言；英文路径、文件名和命令按语义降权，让中文说明主导视线。按终端可见列宽处理 CJK、ANSI 与换行，不以字符串长度计算布局。
- **一个品牌强调色**：青绿用于品牌和关注点；成功、警告、错误各用独立语义色，不混成多个主色。
- **操作有形状**：按钮与普通文字可区分，主次明确，选中态除颜色外还应有标记。
- **输入是独立工作空间**：自适应框体、按需换行，状态变化不推动输入光标；提交后不把整套编辑框堆入历史。

页面向公共组件提供内容和语义，不自行决定相同元素的间距、颜色或标记。视觉变化须核验实际原生帧及交互，不以纸面示意替代终端体验。

## 当前视觉机制

| 元素 | 合同与当前实现 |
|---|---|
| 样式 | `terminal-ui/theme.ts` 统一语义 ANSI 色与间距。品牌 cyan、辅助/边界 dim、成功 green、警告 yellow、错误 red；默认正文使用宿主前景，不在业务文本嵌 ANSI |
| 容器 | `SurfaceChrome` 提供欢迎框、身份和环境信息；主会话欢迎框属于阅读内容，可随阅读卷走，输入与左右信息栏固定在底部。只有实际窗口等级或页面身份改变才切换头部形态，查询条数与加载状态不决定头部高度 |
| 章节与选项 | `ChoiceView` 统一动作及选择反馈；页面只提供内容与状态。凡显示当前选中项的行（普通选项、按钮、候选、技能双行）都经由 `selection-model.ts`、`selection-row.tsx` 这一个原语，标记、纹理字形与铺设规则只在那里定义。选中标记与标签品牌强调，普通选中无底色，选中行在自己的行盒内成一条弱化点阵带：两个及以上的连续空白、列间间隔、各显示行的尾部都铺纹理，单空格保留，文字内容不变；外边距、框线、滚动列不铺。实现是行盒下垫纹理层，文字按段设默认底色盖住单空格，纹理不可选、不进复制、不参与布局。纹理字形在有字体回退的终端（Windows Terminal 等）用迁移前的 `░`，渲染器测得不占 1 列时退回；经典控制台与 Windows 上宿主不明时一律用 ASCII `:`，不出缺字方框。原因：经典控制台不做字体回退，中文系统默认的新宋体没有 `░`；界面画在备用屏幕缓冲区上，其字体可能与启动时主缓冲区的当前字体不同，启动前无法确认。详情保留成功/警告/弱化语义，危险项使用红底，不叠纹理 |
| 状态 | 领域终态决定活动结束，过程流关闭只表示过程传输结束；完成后的指标保持静止。颜色必须伴随可理解的文本 |
| 阅读导航 | 正文下沿一行，只在有阅读信息时占行，无信息时把行高还给正文；是否出现按“不含这一行时的完整高度”判定，行出现后“回到底部”按实际视口判定。左侧给方向与读取状态：“↑ 更早的消息”是进入时的提醒，只在本次访问里用户尚未操作、且上方还有正文时显示（上方正文指视口顶边以上的正文、挂载窗口之前的已备页或 N 已存片段、源端还有更早历史，三者任一；欢迎框不算）。用户发起的第一个输入（按键、粘贴、鼠标按下、滚轮）即收起，本次访问不再出现；被动更新不算操作。访问按会话页与 F2 只读历史各计：换会话、进入或换选历史是新访问，同一会话的重建、模态与 F2 往返不是。为提示占的行随阅读报告交接，第一次上翻由右侧接替，不先收起再撑开。读取中与读取失败、正文待恢复优先，点击按当时显示的那一项执行；右侧在视口下面还有正文时给“↓ 回到底部”（宽屏附 Ctrl+End；macOS 或窄于 60 列不附），落点是对话末尾并恢复跟随。点击或在行上滚轮即阅读；Ctrl+End 回到底部，翻页/回配置页/resize 保留源锚点 |
| 首屏与预取 | 首屏只用首页，不为凑满屏幕多等读取。可输入且空闲（输入框为空、无候选、无待受理提交、无运行）后，按当前宽度的自然行高把更早内容取进已备页，目标为已挂载＋已备 ≥ 两屏；每次进入至多 16 步、40 片，无进展、失败、到头或达到阅读窗口上限即停。已备页不挂载、不改 N 的显示游标与跟随；只在用户向上阅读到顶时揭示，取更早页在途时这次手势等它完成。确证到头时在欢迎框下原有的间隔行写“对话从这里开始”，空新会话不写 |
| 历史用户消息 | 灰底整行标识消息归属，与无底色的助手输出区分；不复用编辑态的输入提示符 |

## 正文的统一语义

N 输出稳定的消息/工具分组身份、角色和源坐标；U 用同一布局进行显示、测量、选区及窗口化。阅读视口占全宽，会话正文（对话与历史阅读）不画应用滚动条，也不为它预留列；正文在视口内部左右各留2列，不再叠父容器留白。原因：全屏终端里应用竖条只能画在宿主内边距与原生滚动条槽的左侧，悬停最右时与宿主滚动条并排、中间隔一段。滚轮、触控板、PgUp/PgDn、阅读导航两端与 Ctrl+End 承担全部滚动。配置、技能等列表页保留最右1列的滚动轨道。用户灰底内左右各2列；助手/工具使用4列标记槽；无标记系统文本不占标记槽。每层列表/引用缩进2列；输入框外边距0列、框内1列。页面与 Placeholder 场景不得另加偏移。

| 内容类型 | 层级、颜色与空间 |
|---|---|
| 用户 | 独立消息组、灰底、正文色；灰底内2列留白，无助手菱形或空标记槽，续行对齐正文 |
| 助手正文 | 独立消息组，起首菱形使用品牌色；正文默认前景 |
| 思考 | 同轮独立块、弱化色；保留其源身份，不与助手正文黏连 |
| 工具/批量工具 | 工具组共用菱形与角色色；运行、成功、失败分语义，失败历史不得投成用户消息 |
| 子任务/过程/系统反馈 | 沿用对应语义角色与明确文本；嵌套内容不另起局部间距体系 |
| Markdown | 段落、标题、列表、引用、代码、表格按节点语义布局；跨传输片的同一节点连续，不重复加空行。普通正文（用户、助手、思考的段落、标题、引用、列表）按词断行：中文句末标点不落行首，英文整词换行，超出一行的连续串逐字断开；代码、表格与工具输出逐字断行。显示与测量共用同一规则，复制取源文本 |
| 阅读层级 | 层级与重点以颜色为主通道（终端里中文粗体几乎不改变字重），只取宿主 ANSI 语义色位，明暗背景都可读：一级标题品牌色加粗加下划线，二级品牌色加粗，三级及以下正文前景色加粗，标题前不加记号；强调暖色（黄色位）加粗；列表记号品牌色、内容正文色；主题分隔线用虚线，与表格框线区分。颜色优先级：链接 > 深灰底上的文字 > 列表记号 > 标题与表头 > 强调。行内代码与用户消息的深灰底是固定的 256 色，前景也取固定浅灰，不用宿主默认前景（浅色背景下默认前景是深色，压在深灰底上读不清）。回复起首菱形落在第一个非空块上，不限块类型 |
| 表格 | 整表框线、弱化色、不可选也不进复制。片段可能在行中间开始或结束，框线只画在能证明的位置：表头上边只在含该行源头的块（from 等于 origin）；行下的线（数据行之间细线、表头下双线、收边）只在含真实行尾的块，行尾由片段源文字中紧邻的换行、来源真实结束，或同一来源在页内后面还有别的节点证明；行的残段不画。只在确定是表尾时收边（同一来源的下一个块不是本表的行，或来源已真实结束），窗口边缘与插入的其他消息不算证据，行尾已知、表尾未定时画行分隔。列宽只由可见表头与可用宽度决定（每列至少容下表头、超长表头按平均宽封顶，余量平均分），不读数据行，所以首屏只有表头、分片、历史重开都得到同一组列宽；长单元格在列内折行。对齐取分隔行声明（左、居中、居右），由原生按每个显示行对齐，多行单元格每行都对齐，不往源文字补空格；选区与屏幕坐标互换时扣除每行的对齐偏移。任一列分到不足 10 格时改为带列名的纵排：窄列里长文字折成十几行、相邻列大片空白，不如纵排易读 |
| 代码/diff | 语法色与增删色分离；行号和增删标记保留，无色仍可读；长行软换行，窄表按列标签堆叠 |

不同消息/工具组之间最多1行空白，与正文已有空行取最大值；同组续片不增加组间距。装饰槽、布局空行、软换行和窄表附加标签不写入复制文本。历史与实时内容执行相同规则。

角色/节点几何由 `body/geometry.ts` 同时供渲染和测量消费；欢迎框偏移纳入同一阅读 owner。窗口变化后等待原生布局完成再按源锚点恢复，不根据尚未重排的行映射累计偏移。列表页轨道出现或消失都不改变内容列宽，也不增加第二个外层滚动容器。

欢迎框保留原品牌、对话和环境内容：左内距3列、右1列，品牌与环境之间1行、底部1行、框后1行。边框中性弱化，品牌与名称强调且名称加粗；不将整个框染成品牌色，也不假定宿主 ANSI 色槽与旧 dim 效果相同。

宽度、间距和字符是可校准的工程取值，不是永恒产品要求。当前历史灰底优先深色终端，不能据此宣称所有浅色配色均已验证可读。

## 动态与静态分区

进行中状态在动态区表达，完成结果进入静态历史；同一状态不在两区重复显示。REPL 动画集中于状态条，spinner 与状态条重画同步，不在已落入历史的文字、工具卡片或重试提示中另开动画源。其他独占面板的加载反馈遵守同样的克制原则，不把“状态条动画”误写成所有界面都必须有状态条。
