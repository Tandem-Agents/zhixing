# CLI 选择模块架构

选择模块承载少量选项的短决策：用户看清行动与后果后选择，模块只返回结构化结果，调用方执行业务。它是终端接入基础设施，不拥有权限、命令或任务推进事实，也不是候选浏览器或复杂表单。

## 职责与请求

调用方提供标题、说明、选项、风险文案、可选详情、补充输入和二次确认。依赖方向是业务调用通用交互；选择模块不调用业务 RPC、不写配置，也不建立审批队列。同一终端同一时刻只允许一个活跃选择，由 N 的交互槽绑定请求与页面，U 返回匹配请求的行动。

业务请求沿用纯类型 SelectionRequest；chooseTerminalSelection 将它映射成共同页面。选项 value 必须唯一，label 非空，description 说明后果，tone 只影响视觉。input 与 confirm 分别表示补充输入与提交前复核，不能仅凭危险色代替确认。details 只供阅读，不产生业务效果。

成功返回 selected 与原业务 value；输入项返回 input，包括显式允许的空字符串。交互取消返回 cancelled 与 escape／ctrl-c／ctrl-d／aborted 原因；非交互端口的 undefined 表示未选择。关闭、返回或失效不能默认批准，也不能无依据推定为业务拒绝。权限的取消与应答映射由[确认接入](../confirmation/surfaces.md)负责。

## 体验合同

通常提供 2～3 个行动，少量选择应让全部行动及关键后果清楚可见。候选过多由业务收敛或使用专用列表；有界窗口和正文分页不能使行动不可达，也不能把关键风险只放在默认看不到的内容中。

| 场景 | 必须保留的行为 |
|---|---|
| 选择 | ↑／↓ 导航，边界不循环；Enter 激活；声明的字符快捷键可选中并激活对应项；禁用项不可执行 |
| 初始项 | 默认首个可用项；initialValue 指定时必须存在且可用，不由布局擅自改变业务默认值 |
| 详情 | 可从请求或选项进入，完整内容有可达阅读方式；查看、翻页和返回不触发选项业务 |
| 补充输入 | 支持普通输入与完整粘贴；按 allowEmpty 校验；返回不得误提交或触发选项快捷键 |
| 二次确认 | 用户明确选择确认后才提交；返回选择层不执行原行动，不把页首的返回按钮当批准 |
| 取消 | Esc、Ctrl+C、Ctrl+D 和请求中止保持可达；具体取消、返回及权限决定含义由接入合同确定 |
| 小屏 | 保留当前状态、说明尺寸不足、暂停不安全提交，并允许取消；恢复尺寸后继续 |

快捷键限单个可打印、非空白 ASCII 字符，大小写归一后唯一，不能占用 Enter、方向键和组合键。补充输入时字符只进入输入字段。快速输入和 bracketed paste 不能被错误解释为一串选项操作。

→ 进入当前选项详情；详情层的 ←／Enter／Esc 返回选择，↑／↓ 阅读、PgUp／PgDn 翻页。输入层 Esc 返回并清空本次补充输入，Ctrl+C／Ctrl+D 和请求中止结束整次选择并保留原因。

## 当前所有者与实现边界

[选择适配](../../../packages/cli/src/terminal/selection.ts)组织选择、正文／详情分页、确认与输入页面；[N 应用](../../../packages/cli/src/terminal/application.ts)持有当前请求和代际；[U 根](../../../packages/terminal-ui/src/root.tsx)统一处理键盘、字段、选项窗口和正文阅读。页面切换不创建新 stdin、raw mode 或屏幕所有者。

当前适配限制请求总内容与选项数；超出安全展示容量时明确禁用确认并允许返回。正文／详情通过有界页面保留完整阅读入口；U 根据视口展示选项窗口。两者不是无限列表，也不等于原先“所有选项永远同屏”的布局。

二次确认提供独立的返回与确认选项，默认确认；第一次 Enter 只进入确认页，第二次 Enter 才确认，Esc 返回选择。输入页提供提交与返回。N 校验声明行动、快捷键唯一性、初始可用项和取消原因；U 跳过禁用项，页面刷新保留仍可用的当前选项。

选择、权限、推进、工作场景与停止流程共用同一页面和输入所有权。[权限映射](../../../packages/cli/src/terminal/confirmation.ts)只提供真实可用的授权选项，保持持久规则范围与二次确认。旧 TerminalConfirmationRenderer、SelectOperationRegion 和 selection presenter 已退役。

页面替换、Abort、断连、退出须结束当前请求，释放局部信息来源；迟到回执不能应用到新页面。业务效果只在明确行动后沿领域调用链执行，失败不显示成功。

## 维护判据

同时核对请求映射、初始项、禁用项、快捷键、完整后果、详情往返、补充输入、二次确认、取消原因、小屏保状态及返回后的草稿。真实按键与页面测试不能由纯请求快照代替；业务不得另建按键监听或屏幕 owner。公共视觉见[输入视觉](input-visual.md)与[屏幕渲染](screen-rendering.md)。
