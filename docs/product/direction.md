# 产品方向

**从通用个人助手走向伴身智能：长期伴随用户，共同思考、自主办事，服务真实的生活与工作。**

**围绕人，长期伴随。**

以用户的生活与工作为中心，让合作跨越设备与软件入口延续，不局限于用户打开某个工具的时刻。

**一起想清楚，也能把事办成。**

共同思考时，帮助用户澄清问题、形成判断。受托办事时，面对陌生问题或能力缺口，主动寻找、学习和组合办法，推进到实际结果，不要求用户先给出解决步骤。

**系统承担复杂度，用户保有主导权。**

知行负责组织能力、执行和维护，只在确需本人决定或操作时请求用户参与。目标、授权和重要决定仍由用户掌握。

**成为值得长期托付的伙伴。**

认真对待托付，保持独立判断，无法完成时如实说明。通过持续合作积累方法，形成了解与默契。
