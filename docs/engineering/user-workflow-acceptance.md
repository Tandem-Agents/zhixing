# 开发完成后的真实使用验收

在整项功能开发或架构改动的全部实施单元完成并集成后、向用户整体交付前，集中按真实使用方式验收成品：既确认需求兑现，也主动发现预设用例之外的问题。本方法用于原流程的最终验收，不增加重复轮次，不介入单元内原有的开发验证与审查。

## 从使用任务确定范围

从原始需求、公开用法与实际可达入口列出本次承诺及受影响的既有使用，再沿生产调用关系核对遗漏，包括共享状态、配置和数据的其他消费面。正常使用所需的基本可用性、正确性、安全与耐久保证同属验收范围，不因需求未逐条写出就排除；不能让改动文件或已有测试定义范围。

按影响和既定兼容范围选择首次、已有状态（含变更前的配置与数据）、普通习惯与合法边界输入、失败及恢复路径；不要只用开发者准备好的空环境和规范化输入。检查各单元合在一起后的实际结果，不能用各单元分别通过代替成品验收。

## 从实际入口完成任务

使用符合交付形态的构建或安装产物，记录可对应到源码状态与产物的版本依据。图形与终端界面走真实交互，命令走正式命令行，服务走公开接口，库走实际消费者集成；内部模块沿真实调用链验到消费者结果。

保留使用者会经历的启动、配置、等待、返回和接续。在完成主要动作后继续相关操作，按功能需要检查重新进入、重启或失败后的结果；不能以页面打开或成功提示代替任务实际完成。涉及可取消或可中断操作时，核对相应分支的结束状态及后续可用性。

允许隔离数据、复用可靠驱动与控制外部依赖，但必须说明哪些部分真实、哪些被替代，不得替掉正在验收的产品链路。受控服务可证明产品如何响应其输入，不能代证真实外部服务、账号或网络已经可用；任务明确要求验证的真实目标、发布源或安装形态不得由夹具替代。自动驱动须确认动作实际生效，未进入目标场景不记通过。

## 观察整个使用过程，处理实际异常

检查不能只盯预设断言。观察使用中能否看懂、正确操作、合理等待、得到结果并继续使用，以及前一次动作是否留下错误状态。依被验效果选取可独立复查的直接证据并保护敏感信息：

- 涉及图形或终端界面的交付，包括影响界面的状态或架构改动，实际查看并保留关键宿主画面，核对整屏、状态转换与下一步操作。经核查确无可用显示或视觉捕获条件时，完成可做的交互核验并留下视觉未验项，按未达项处理；不得用文本或状态转储代证，也不据此宣布界面通过。
- 命令和接口核对实际请求、响应、退出或错误及后续效果；提示与返回值遵守相应用户或协议合同。
- 持久状态核对提交结果及需要的重启回读；异步操作核对完成、失败或取消后的状态与继续使用，不只看接纳回执。
- 记录受影响的启动与关键交互从动作发出到真正可继续的实际等待，对照需求和改前正常基线判断。未预设秒数不免除对明显卡顿和退化的查证；新路径结合任务性质与实际可用性判断，不以首帧、内部回调或人为等稳跳过等待。

实际观察到的异常，即使不在原用例里、脚本没有报错、以前通过或原已存在，也须记录并查明：是产品缺陷、驱动问题、环境限制，还是符合需求的行为。妨碍本次路径正常使用的既有缺陷仍须处理，不能借“原来就有”放行；范围外且不影响本次使用的遗留问题另行记录，不借此扩面。缺陷、改进建议与用户偏好按需求和事实区分，不能靠改分类掩盖未达标。

发现缺陷后沿实际共享机制核对同类入口与消费面，确认影响再修复，从原使用路径及受影响的连续操作复验。不能只修碰到的一点，也不因名称相似就扩为全仓重测。

## 以独立检查与实际结果放行

沿用现有任务或审查记录，写清交付版本、真实与替代边界、已通过操作的输出、画面、状态或耗时依据，以及异常处置和未验部分。记录规模随任务而定，不另设固定表单；脚本通过计数或口头摘要不能代替实际使用证据，驱动未生效或尚未查清的结果不记通过。

自验、独立验收和适用质量门沿用原任务分工与[协作规则](../workbench/cross-session-collaboration.md)，不另设角色、分级或审批流程。

独立审查者先从用户目标、公开入口及已知故障的事实描述确定范围，自选场景、顺序与判据，亲自验证核心使用、风险交界与遗漏项，再对照实施方关键已通过项的原始证据补核。已知故障与反例如实提供，不夹带作者的根因、方案或通过判断；冷执行不预读实现、既有测试及开发过程分析。可以复用操作工具，不能只重跑实施方原有场景或接受其摘要。

最终交付须有该版本从核心入口到任务完成及接续使用的整体验证依据，不能仅拼接各单元的局部成绩。验收发现问题并修复后，重建必要产物，只复验受影响的核心路径、共享机制及相关连续操作；按原独立验收职责复核后放行。未受影响且仍有效的证据复用，不因一次修复重启整轮，也不将中间版本成绩无条件外推。

未兑现明确承诺、正常使用中破坏基本可用性或正确性、安全与耐久保证、受影响既有能力明显退化，以及必要验证缺口，均阻断交付，不得借问题分类、登记延期或意见一致绕过。未违反明确完成条件且不影响正常使用的轻微瑕疵，如实记录后续处置，不为零瑕疵无限打磨，也不自行降低用户标准。

确有不可自行解除的条件，完成其余可做工作并如实报告未达项，不伪造通过；改变用户目标或验收边界仍由用户决定。已满足要求、必要验证成立即结束，不以无限探索或检查次数代替交付。
