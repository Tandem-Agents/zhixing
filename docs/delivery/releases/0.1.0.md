# Zhixing 0.1.0

> Status: unreleased candidate. This is the authoritative release-note source for version `0.1.0`; the package is not yet available from npm.

## What this release contains

Zhixing is a self-hosted personal agent for recoverable conversation and real task execution on the user's own devices. The first release includes:

- recoverable conversations, history, naming, clearing, and work-scene context;
- file reading and writing, content search, and command execution within trust, permission, and confirmation boundaries;
- work scenes, task lists, schedules, multi-perspective analysis, and subtask orchestration;
- Skills and configured MCP services; and
- optional Feishu and paired-device capabilities.

## Supported installation

The initial supported environment is Windows 10/11 x64 with Node.js `>=24.0.0`. After the package is published, the supported installation entry is:

```powershell
npm install -g @zhixing/cli
zz --version
```

Other operating systems, CPU architectures, package managers, and installation methods are outside the initial support scope. Follow the [English quick start](../../../README.en.md) or [中文快速开始](../../../README.md) for setup and a first task.

## Data, execution, and cost boundaries

- Runtime state is stored on the user's devices, but prompts, context, and tool results may be sent to the configured model provider.
- MCP services, message channels, model providers, and network tools contact external services whose permissions, retention, availability, and charges apply.
- File and command tools have real effects. Trust, permission, and confirmation policies are not an operating-system-level strong isolation sandbox.
- Provider credentials belong in the device-local SecretStore, not public configuration, prompts, repositories, issues, or logs.

Read the [security policy](../../../SECURITY.md) before reporting a suspected vulnerability. A project-controlled private reporting channel is not yet enabled; version `0.1.0` must not be declared ready for public release until that release prerequisite is resolved.

## Maintenance and removal

Zhixing does not update itself in the background, and downgrade is unsupported after a newer version has run. Use an explicit maintenance stop before reinstalling or upgrading. `zz app remove` unregisters and stops the program while retaining user data; permanently removing the current device and its local data is a separate destructive operation.

See the [installation, maintenance, and release guide](../../../research/design/modules/distributed-runtime/release-and-maintenance-guide.md) for the complete procedure.

## Known limitations

- Only Windows 10/11 x64 and Node.js 24 or newer are initially supported.
- Strong operating-system isolation, long-term memory, an unlimited plugin platform, background updates, and downgrade are not part of this release contract.
- External-service availability, model quality, provider data handling, and provider charges are not controlled by Zhixing.
