# 产品待办

以下事项不阻塞当前主线。

- [ ] **优化 AI 服务商接入体系。** 梳理接入范围、配置方式和使用体验，重新设计并优化接入体系，提高灵活性与易用性。[问题描述](../tasks/model-provider-access-optimization.md)

- [ ] **核查外部智能体通信入口。** 核实是否提供外部智能体可使用的消息接收与交互方式，明确入口、用法及能力边界。

- [ ] **建设让知行了解自身的内置技能。** 让知行能够按需了解自身能力、使用方式、配置与限制，正确回答和处理与自身有关的问题；这是产品内置能力，不是开发协作者使用的技能。

- [ ] **建立智能体整体评估体系。** 系统理解智能体评估（Agent Evals）的概念与方法，围绕知行完成真实任务的效果，逐步建立能力、可靠性、安全性和效率的评估体系；持续积累代表性任务、评测数据、评判标准、工具与结果，支撑能力边界识别、版本比较和改进验证，不以单一跑分代替整体判断。
