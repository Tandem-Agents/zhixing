# 失败复盘与可复用教训

遇到诊断反复、架构误判或效率失控时，按下表查找相似信号，阅读对应复盘的原因与适用边界。这里用于改进下一次工作，不是事故流水账；历史实现与耗时不作为当前状态。

| 遇到的信号 | 可借鉴的经验与复盘 |
|---|---|
| 一条CLI路线失败就断言整体做不到，外围桥接反复重写 | [通信能力误判](2026-10-20-agent-communication-capability.md)：区分能力边界与搜索边界，重审变化的约束，以原会话关联回复验证闭环 |
| 真实输入不明，反复扩字符处理范围仍失败 | [起首空行诊断](2026-05-07-anchor-empty-line.md)：取得输入证据，区分视觉规范化与显示宽度，检查合法字符边界 |
| 改动后仍失败，或换宿主后文本输入消失 | [构建与输入分流遗漏](2026-05-14-confirm-input-paste-misroute.md)：核对实际运行产物，按调用者协议消费输入，区分修复依据与原因假设 |
| 面板退出后所有输入冻结，状态字段却正常 | [资源交接诊断](2026-05-20-confirm-input-freeze-conpty.md)：检查共同路径与中间资源重置，不以健康快照排除应用缺陷 |
| 不同内容出现相同故障，诊断却反复锁定单个对象 | [屏幕诊断偏航](2026-05-09-screen-render-misdiagnosis.md)：寻找位置与环境共性，核对承诺，切换验证维度 |
| 内部测试通过，公开调用仍不兼容 | [公共 API 兼容盲区](2026-07-12-public-api-compatibility-blind-spot.md)：在兼容承诺范围内检查声明、真实入口与调用行为 |
| 恢复或压缩后重复初始化，工作成果归零 | [重置指令重放](2026-07-14-compaction-replays-destructive-reset.md)：检查动作身份、消费记录与恢复依据，不盲目清空 |
| 验证设施持续膨胀，非核心观测阻塞交付 | [性能门禁过度设计](2026-08-01-performance-gate-overdesign.md)：先核实必要性、风险价值和运行成本 |
| 证据声明不成立，被直接评成严重产品缺陷 | [验收夸大误判](2026-08-02-acceptance-gap-misclassified-as-product-blocker.md)：分别判断生产事实、必要证据和验收设计 |
| 验证长时间无结果，换参数重跑，进度却持续上涨 | [最终验证耗时失控](2026-08-06-final-validation-overrun.md)：预算验证总账、保留有效证据、停止无依据重复 |
| 收尾全量冒出新失败、单个任务远超预期、全量一次几十分钟 | [既有失败清零超时](2026-10-23-x1-validation-loop-overrun.md)：复用有效基线、按影响面补测并分类估时，用仓库锁定的测试运行器并行跑，以HEAD导出树作对照，每项定时间盒，测试分快慢车道 |
| 加并发后测试反而变慢并出现非确定失败，估时一再低估 | [并发换不来吞吐](2026-10-23-test-speed-concurrency-floor.md)：先做等待记账和 1/N 进程微基准，确认瓶颈是否随并发扩展；预计用可比实耗、实测并行度与拖尾，不用“合计 ÷ worker 数” |
| 有界工作量返修多轮，每轮指标变好、复核又发现成本换了位置 | [成本换位置的循环](2026-10-23-bounded-work-cost-shifting.md)：交审前用全 fs 计数分阶段、两规模对照，计入新增文件的字节、物化、缺失探测与写入；有线性转移先改结构再验证 |
| 对端长时间收不到消息、周期任务停了，监听进程却显示健康 | [一次超时让通知通道停摆](2026-10-24-notification-wedged-after-one-timeout.md)：查投递状态里有没有不重试的终态；“等待收取”门禁只建立在确认送达上；失败与未知都退避重试；周期快照以新代旧 |
| 收尾全集刚启动，自检又发现要改的地方，整轮作废重跑 | [自检未完先跑全集](2026-10-24-full-run-before-self-review.md)：受影响全集是自检之后的一次性确认，不是自检的替代；先把每个断言依赖的路径（顺序、重复、边界归属）核完，再一次性启动 |
| 扩展旅程驱动后长跑中途结束或启动即退出码 64；事后阶段账窗口内没有日志；“就绪”后首发被拒 | [扩展既有旅程驱动](2026-10-24-journey-driver-limits-and-rotated-logs.md)：先读外部套件的参数上限与寿命，超限分段续跑；关注窗口结束即快照日志；就绪判据对齐真实接纳并逐帧核对启动画面；修提示与准入不一致时用例同时驱动真实准入入口 |
| 过滤构建去构建了被排除的包；构建报 terminal-ui `spawn bun ENOENT`；测试报“X 不是 X 的实例”；代码没变却成片失败 | [小写盘符工作目录](2026-10-24-lowercase-drive-letter-cwd.md)：先读构建日志第一处异常，怀疑模块重复加载；昂贵验证前用 node 核对工作目录盘符，构建失败即中止整条链 |
| 状态改成按需装入后，领域用例与差分全过，全集里却有“待装入”直接抛给调用方 | [按键工作集漏掉事务外调用方](2026-10-25-lazy-working-set-outside-callers.md)：列出每个同步读取的全部调用点，按事务内/外分类；事务外的每处配冷实例用例与撤回变异，姊妹领域成对检查 |
| 前台被后台长时间挤掉，看起来后台“一直在忙” | [后台被挡住而非在推进](2026-10-25-blocked-not-busy-background.md)：按秒采样后台的持久进度，区分推进与空转；受阻步骤不反复取锁；续读视图要么显式释放、要么无状态 |
| 机器繁忙时依赖样本新鲜度的准入被拒，单跑正常，阈值不许放宽 | [负载下样本过期](2026-10-25-sample-freshness-under-load.md)：拆段计量采样链路，一维缺失不连带其他维度，先小实验再改结构；`Atomics.waitAsync` 不保持事件循环存活 |
| 规模用例有界、阶段账仍见整读；同一项反复查出新的整读 | [规模用例的证明止于替身](2026-10-25-scale-proof-stops-at-the-fake.md)：先看规模用例里哪些依赖是替身；整链读量用真实下游或同候选阶段账证明；宣称有界前列全调用方与读取入口，含非单机路径 |
| 状态目录复制成功，却出现权限变化或旧数据无法打开 | [Windows 状态目录迁移记录](2026-08-17-windows-codex-home-migration.md)：完整过程与取舍，核对权限、联接、绝对路径及新旧数据访问，区分备份与现用数据 |
