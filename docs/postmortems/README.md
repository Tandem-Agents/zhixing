# 失败复盘与可复用教训

遇到诊断反复、架构误判或效率失控时，按下表查找相似信号，阅读对应复盘的原因与适用边界。这里用于改进下一次工作，不是事故流水账；历史实现与耗时不作为当前状态。

| 遇到的信号 | 可借鉴的经验与复盘 |
|---|---|
| 真实输入不明，反复扩字符处理范围仍失败 | [起首空行诊断](2026-05-07-anchor-empty-line.md)：取得输入证据，区分视觉规范化与显示宽度，检查合法字符边界 |
| 改动后仍失败，或换宿主后文本输入消失 | [构建与输入分流遗漏](2026-05-14-confirm-input-paste-misroute.md)：核对实际运行产物，按调用者协议消费输入，区分修复依据与原因假设 |
| 面板退出后所有输入冻结，状态字段却正常 | [资源交接诊断](2026-05-20-confirm-input-freeze-conpty.md)：检查共同路径与中间资源重置，不以健康快照排除应用缺陷 |
| 不同内容出现相同故障，诊断却反复锁定单个对象 | [屏幕诊断偏航](2026-05-09-screen-render-misdiagnosis.md)：寻找位置与环境共性，核对承诺，切换验证维度 |
| 内部测试通过，公开调用仍不兼容 | [公共 API 兼容盲区](2026-07-12-public-api-compatibility-blind-spot.md)：在兼容承诺范围内检查声明、真实入口与调用行为 |
| 恢复或压缩后重复初始化，工作成果归零 | [重置指令重放](2026-07-14-compaction-replays-destructive-reset.md)：检查动作身份、消费记录与恢复依据，不盲目清空 |
| 验证设施持续膨胀，非核心观测阻塞交付 | [性能门禁过度设计](2026-08-01-performance-gate-overdesign.md)：先核实必要性、风险价值和运行成本 |
| 证据声明不成立，被直接评成严重产品缺陷 | [验收夸大误判](2026-08-02-acceptance-gap-misclassified-as-product-blocker.md)：分别判断生产事实、必要证据和验收设计 |
| 验证长时间无结果，换参数重跑，进度却持续上涨 | [最终验证耗时失控](2026-08-06-final-validation-overrun.md)：预算验证总账、保留有效证据、停止无依据重复 |
| 状态目录复制成功，却出现权限变化或旧数据无法打开 | [Windows 状态目录迁移记录](2026-08-17-windows-codex-home-migration.md)：完整过程与取舍，核对权限、联接、绝对路径及新旧数据访问，区分备份与现用数据 |

事件经过与未决调查归入 `docs/incidents/`；独立工程经验由[工程经验正文](../engineering/state-replay-contract-lessons.md)等对应文档维护，复盘不重复定义。
